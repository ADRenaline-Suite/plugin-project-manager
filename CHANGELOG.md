# Changelog

## [0.0.1] - 2026-10-31

### Added

- Use case in the casual or fully dressed template. A project can add its own template under `templates/use-case/`.
- Cross-repository task: one result and the change in each repository.
- Progress report. A project can add its own template under `templates/status-report/`.
- Sprint plan: goal, timebox, selected items, and the delivery plan.
- Ordered backlog. The tracker link is recorded only when the person gives it.
- Commands `/pm-help`, `/pm-use-case`, `/pm-cross-repo-task`, `/pm-status`, `/pm-sprint`, and `/pm-backlog`.
